# Proyecto de Automatizacion - TQA

## Descripcion
Este repositorio esta destinado al desarrollo de pruebas automatizadas para el Sistema de Gestion del Sindicato de Transporte La Paz.

El objetivo es comprobar el funcionamiento de los modulos del sistema mediante herramientas de automatizacion, facilitando la deteccion de errores y la validacion de sus funcionalidades.

## Objetivos
- Identificar funcionalidades que puedan automatizarse.
- Desarrollar scripts de pruebas automatizadas.
- Ejecutar pruebas y registrar resultados.
- Detectar errores y verificar correcciones.
- Organizar evidencias de las pruebas.

## Modulos a evaluar
- Inicio de sesion y control de acceso.
- Gestion de vehiculos.
- Registro de conductores y propietarios.
- Control de pagos semanales.
- Consulta de deudas.
- Seguimiento GPS y rutas.
- Generacion de reportes.

## Estructura
- tests/: scripts de pruebas automatizadas.
- configuracion/: configuracion del entorno.
- evidencias/: capturas y resultados.
- documentacion/: documentos relacionados con las pruebas.

## Tecnologias
- Git y GitHub para control de versiones.
- Herramientas de automatizacion por definir durante la materia.
